# Frontend — History

## What I Know About This Project

- Taskpane add-in for PowerPoint using React + TypeScript + Office.js
- Fluent UI v9 for all UI components with theme detection
- Components: WorkspacePicker, ReportList, PageList, InsightPanel
- Image insertion via PowerPoint JavaScript API (shapes.addImage)
- Batch insertion creates one slide per report page
- React Query (@tanstack/react-query) for API state management
